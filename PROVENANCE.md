# Implementation provenance

This repository contains an independent implementation created for interoperability with a user's own Samsung Reminder data.

- No Samsung APK, decompiled Samsung source, copied Samsung code, Samsung artwork, captured account payload, access token, or user screenshot is included.
- Protocol constants and schemas were implemented from observed runtime behavior, public documentation, and user-provided visual references. Those references are not redistributed here.
- The interface and generic checkmark application icon are original project material inspired by platform behavior, not extracted Samsung assets.
- Category glyphs are mapped to Lucide icons under Lucide's ISC license; they are not Samsung icon assets.
- Generated Tauri schemas and dependency lockfiles remain identifiable as generated or third-party metadata.

This provenance record describes the repository contents and development inputs; it is not a legal conclusion about private-interface access. See [LEGAL.md](LEGAL.md).
